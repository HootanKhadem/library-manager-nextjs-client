# toumaar PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add install metadata, branded icons, and safe offline navigation fallback.

**Architecture:** Next.js serves manifest and static icons. A root client component registers a service worker. Worker caches only public offline assets and intercepts document navigation with network-first fallback.

**Tech Stack:** Next.js 16 App Router, React 19, browser Service Worker and Cache APIs, Jest.

---

### Task 1: Install metadata and assets

**Files:** Create `src/app/manifest.ts`, `public/pwa-192.png`, `public/pwa-512.png`, `public/pwa-maskable-512.png`, `src/app/apple-icon.png`; modify `src/app/layout.tsx`.

- [x] Generate PNG icons from toumaar open-book mark; keep book within central safe area for maskable icon.
- [x] Add manifest with `name`, `short_name`, `id`, `start_url`, `scope`, `display`, brand colors, and icon entries.
- [x] Add theme and Apple web app metadata to root layout.
- [x] Test manifest fields and icon dimensions.

### Task 2: Offline fallback worker

**Files:** Create `public/offline.html`, `public/sw.js`, `src/components/PwaRegistration.tsx`; modify `src/app/layout.tsx`, `next.config.ts`.

- [x] Add self-contained offline page with no network assets.
- [x] Cache offline page and public icons on worker installation; clear prior toumaar PWA caches on activation.
- [x] Intercept only same-origin document navigations. Fetch from network; on failure return cached offline page.
- [x] Register worker after hydration; send no user data to cache.
- [x] Set `/sw.js` response headers for JavaScript type and revalidation.
- [x] Test navigation fallback and confirm API and non-navigation requests bypass worker.
